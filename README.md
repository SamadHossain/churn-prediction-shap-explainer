# Customer Churn Prediction & Explainability

A machine learning project for predicting customer churn and explaining model predictions using SHAP.

## Project Overview

This project analyzes customer data to identify customers who are likely to leave a telecommunications service.

The workflow includes data cleaning, exploratory data analysis, feature engineering, machine learning, model evaluation, hyperparameter tuning, and SHAP-based model explainability.

## Key Techniques

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Logistic Regression
- XGBoost
- SMOTE for class imbalance
- Cross-validation and hyperparameter tuning
- ROC-AUC evaluation
- Business-oriented probability threshold tuning
- SHAP explainability
- Customer segmentation using K-Means

## Tools

Python • Pandas • NumPy • Matplotlib • Seaborn • Scikit-learn • XGBoost • SHAP
